# רני אלון – עמוד זיכרון

אתר פשוט לשיתוף סיפורים, תמונות, הקלטות וסרטונים.

- כל אחד עם הקישור יכול להוסיף זיכרון: טקסט, תמונות, סרטונים, קבצי שמע או הקלטה ישירה מהמיקרופון.
- בכל פריט בוחרים **כולם** או **המשפחה בלבד**.
- **קוד משפחה** – רואים גם את הפריטים של המשפחה ומורידים את הכל (ZIP עם הקבצים המקוריים ועמוד `index.html` שנפתח גם בלי אינטרנט).
- **קוד מנהל** – בנוסף: מחיקה, שינוי נראות, עריכת השם והשורה שמתחתיו, והחלפת התמונה.
- האתר לא מופיע במנועי חיפוש. כשמשתפים את הקישור בוואטסאפ מופיעים השם והתמונה.

## מבנה

| | איפה |
|---|---|
| האתר והשרת | Vercel (אפליקציית Express, מזוהה אוטומטית) |
| טקסטים, שמות, הגדרות | Neon Postgres (הטבלאות נוצרות לבד בהפעלה הראשונה) |
| תמונות, סרטונים, הקלטות | Vercel Blob **פרטי**. הקבצים עולים ישירות מהדפדפן ונפתחים רק דרך קישורים חתומים וזמניים |

## העלאה ל-Vercel

1. **Add New → Project** ובוחרים את הריפו `rani-`. Vercel מזהה Express לבד, ואין צורך לשנות הגדרות. לוחצים **Deploy**. בשלב הזה העמוד עדיין לא יעבוד, וזה צפוי.
2. בלשונית **Storage** של הפרויקט: **Create → Neon (Postgres)**, ומחברים לפרויקט.
3. שוב ב-**Storage**: **Create → Blob**, בוחרים **Private** ומחברים לפרויקט.
4. ב-**Settings → Environment Variables** מוסיפים:
   | משתנה | ערך |
   |---|---|
   | `ADMIN_CODE` | קוד ארוך שרק אתם יודעים |
   | `FAMILY_CODE` | קוד שנמסר למשפחה |
5. ב-**Deployments**, בפריסה האחרונה: **⋯ → Redeploy**, כדי שההגדרות ייכנסו לתוקף.
6. נכנסים פעם אחת עם `https://<הכתובת>/?k=<ADMIN_CODE>`, לוחצים **עריכת עמוד** ומעלים את התמונה.

קישור כניסה ישירה למשפחה: `https://<הכתובת>/?k=<FAMILY_CODE>`

## מגבלות שכדאי להכיר

- **נפח קבצים:** במסלול Hobby של Vercel יש 1GB אחסון ל-Blob. מעבר לזה הגישה לקבצים נחסמת לעד 30 יום. במסלול Pro יש 5GB, ומעבר לזה התשלום הוא לפי שימוש. אם מצפים להרבה סרטונים, עדיף Pro.
- **הורדת הכל** מחולקת לקבצי ZIP של כ-250MB, כי לכל בקשה ב-Vercel יש מגבלת זמן.
- גודל מרבי לקובץ בודד: 1GB (משנים ב-`MAX_FILE_MB`).

## הגדרות נוספות (לא חובה)

| משתנה | ברירת מחדל | |
|---|---|---|
| `PERSON_NAME` | `רני אלון` | השם בראש העמוד (אפשר גם לערוך מהאתר) |
| `MAX_FILE_MB` | `1024` | גודל מרבי לקובץ בודד |
| `EXPORT_PART_MB` | `250` | גודל כל חלק בהורדת הכל |

## הרצה מקומית

צריך Postgres מקומי. בלי Blob, הקבצים נשמרים בתיקייה `data/`.

```bash
npm install
cp .env.example .env      # למלא ADMIN_CODE, FAMILY_CODE, DATABASE_URL
npm start                 # http://localhost:3000
```

`npm run bundle` בונה מחדש את `public/vendor/blob-client.js`, ספריית ההעלאה של Vercel Blob לדפדפן.
