# רני אלון – עמוד זיכרון

אתר פשוט לשיתוף סיפורים, תמונות, הקלטות וסרטונים.

- כל אחד עם הקישור יכול להוסיף זיכרון: טקסט, תמונות, סרטונים, קבצי שמע או הקלטה ישירה מהמיקרופון.
- בכל פריט בוחרים **כולם** או **המשפחה בלבד**.
- **קוד משפחה** – רואים גם את הפריטים של המשפחה, ואפשר להוריד את הכל (ZIP עם הקבצים המקוריים ועמוד `index.html` שנפתח גם בלי אינטרנט).
- **קוד מנהל** – כל מה שהמשפחה רואה, ובנוסף מחיקה, שינוי נראות, עריכת השם והשורה שמתחתיו, והחלפת התמונה.
- האתר לא מופיע במנועי חיפוש (`noindex`). כשמשתפים את הקישור בוואטסאפ מופיעים השם והתמונה.

## הרצה מקומית

```bash
npm install
cp .env.example .env      # למלא ADMIN_CODE ו-FAMILY_CODE
npm start                 # http://localhost:3000
```

## העלאה לאוויר (Railway, בערך 10 דקות)

1. נכנסים ל-[railway.com](https://railway.com), ואז **New Project → Deploy from GitHub repo**, ובוחרים את הריפו הזה.
2. בשירות שנוצר, בלשונית **Variables**, מוסיפים:
   | משתנה | ערך |
   |---|---|
   | `ADMIN_CODE` | קוד ארוך שרק אתם יודעים |
   | `FAMILY_CODE` | קוד שנמסר למשפחה |
   | `DATA_DIR` | `/data` |
3. **אחסון:** מוסיפים Volume לשירות (קליק ימני על השירות → **Attach Volume**), עם Mount path ‏`/data`.
4. בלשונית **Settings → Networking** לוחצים **Generate Domain**. זה הקישור לאתר.
5. נכנסים פעם אחת עם `https://<הכתובת>/?k=<ADMIN_CODE>`, לוחצים **עריכת עמוד** ומעלים את התמונה.

קישור כניסה ישירה למשפחה: `https://<הכתובת>/?k=<FAMILY_CODE>`

> אפשר גם Render או Fly.io. צריך שירות Node עם דיסק קבוע שמחובר ל-`DATA_DIR`, או אחסון בענן (בהמשך).

## אחסון: מה צריך?

כן, צריך אחסון קבוע. בלי אחסון כזה, כל הקבצים נמחקים בכל עדכון או הפעלה מחדש של השרת. יש שתי אפשרויות:

**א. דיסק (Volume) – הכי פשוט.** זה מה שמוגדר בשלב 3 למעלה. ב-Railway Hobby הנפח מוגבל ל-5GB, וזה מספיק להרבה תמונות והקלטות, אבל לא להרבה סרטונים.

**ב. Cloudflare R2 – כשמצפים להרבה וידאו.** 10GB בחינם, ואחר כך כ-0.015$ לג'יגה בחודש, בלי תשלום על הורדות.
1. ב-Cloudflare: **R2 → Create bucket** (למשל `rani-memorial`). הבאקט נשאר פרטי.
2. **R2 → Manage API Tokens → Create API Token**, עם הרשאת **Object Read & Write** לבאקט הזה.
3. מעתיקים למשתני הסביבה של השרת:
   ```
   S3_BUCKET=rani-memorial
   S3_ENDPOINT=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
   S3_ACCESS_KEY_ID=...
   S3_SECRET_ACCESS_KEY=...
   ```
   כשמוגדר `S3_BUCKET`, הכל נשמר בבאקט (גם הנתונים) ואין צורך ב-Volume. לא צריך להגדיר CORS.

עובד גם עם AWS S3, Backblaze B2 וכל שירות תואם S3.

## הגדרות נוספות

| משתנה | ברירת מחדל | |
|---|---|---|
| `MAX_FILE_MB` | `2048` | גודל מרבי לקובץ בודד |
| `PERSON_NAME` | `רני אלון` | השם בראש העמוד (אפשר גם לערוך מהאתר) |
| `S3_REGION` | `auto` | |
| `S3_PREFIX` | – | תיקייה בתוך הבאקט |

## הערות

- צריך להריץ **מופע אחד** של השרת (לא להגדיל ל-replicas).
- גיבוי: כפתור **הורדת הכל** בתחתית העמוד (למשפחה ולמנהל).
- החלפת קוד משפחה או קוד מנהל מוציאה את כל המחוברים.
